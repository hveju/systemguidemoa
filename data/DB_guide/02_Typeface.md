## 0. 메타

### 0.1. 분류

- group: Foundation

### 0.2. 타입 목록

- Display: 시각적 강조를 위한 최상위 대형 텍스트 스타일

- Body: 본문, 주요 설명 및 인터랙션 요소의 레이블에 사용하는 텍스트 스타일
- Caption: 디스크립션, 유의사항 및 보조 정보에 사용하는 텍스트 스타일

## 1. 개요

### 1.1. 정의

- Typeface는 화면 내 콘텐츠의 역할과 정보 위계에 따라 텍스트 스타일을 구분하고, 일관된 타이포그래피를 적용하기 위한 디자인 기준입니다.
- 콘텐츠의 중요도, 정보 전달 목적에 따라 적절한 텍스트 스타일을 선택하여 가독성과 정보 위계를 유지합니다.
- 텍스트의 역할에 적합한 타입과 레벨을 선택하고, 정의된 font-size, line-height 및 기타 타이포그래피 속성을 준수합니다.

### 1.2. 적용 상황

- 페이지 및 콘텐츠의 제목, 본문, 보조 정보 등 화면 내 정보 위계를 구분할 때 사용합니다.
- 버튼, 탭, 입력 요소 등 사용자 인터랙션을 안내하는 텍스트에 적용합니다.
- 콘텐츠의 중요도와 사용 목적에 따라 텍스트의 강조 수준과 가독성을 조정할 때 사용합니다.
- 다양한 화면과 컴포넌트에서 일관된 텍스트 스타일을 유지할 때 적용합니다.

## 2. 사용 규칙

### 2.1. 공통 규칙

- status: MUST
    
    content: 텍스트의 역할과 정보 위계에 따라 Display, Heading, Title, Body, Caption 중 적절한 타입을 선택합니다.
    
- status: MUST
    
    content: 각 타입과 레벨에 정의된 font-size, line-height, letter-spacing을 적용합니다.
    
- status: MUST
    
    content: 정의된 타이포그래피 스펙을 임의로 변경하지 않습니다.
    
- status: SHOULD
    
    content: PC에서는 md, 모바일에서는 sm을 기본 레벨로 사용하는 것을 권장합니다.
    
- status: SHOULD
    
    content: 동일한 역할과 정보 위계의 텍스트에는 일관된 타입과 레벨을 적용합니다.
    
- status: ALLOW
    
    content: 화면 구성, 정보 위계, 가독성 등을 고려하여 권장 레벨에서 한 단계 상위 또는 하위 레벨로 조정할 수 있습니다.
    
- status: AVOID
    
    content: 시각적인 크기만을 기준으로 텍스트 타입을 선택하지 않습니다.
    
- status: AVOID
    
    content: 정의되지 않은 타입이나 레벨을 임의로 생성하지 않습니다.
    

### 2.2. 타입 선택 기준

- Display:
    - 시각적 임팩트가 중요하고 화면에서 가장 강조해야 하는 핵심 메시지를 표현할 때 선택합니다.
    - 메인 히어로, 브랜드 캠페인, 프로모션 등 시각적 임팩트가 중요한 대형 텍스트에 사용합니다.
- Heading:
    - 페이지와 섹션의 정보 위계를 구분하고, 콘텐츠의 시작을 알리는 제목에 선택합니다.
- Title:
    - 페이지나 섹션 전체가 아닌 배너, 카드, 리스트 등 개별 콘텐츠와 컴포넌트의 제목에 사용합니다.
- Body:
    - 본문, 상품 설명, 이용 방법 등 주요 정보를 전달하는 서술형 텍스트에 사용합니다.
    - 버튼, 탭 등 사용자 인터랙션을 안내하는 컴포넌트 레이블에 사용합니다.
- Caption:
    - 유의사항, 이용 조건, 디스크립션 등 주요 콘텐츠를 보완하는 텍스트에 사용합니다.
    - 테이블의 텍스트와 입력 필드 항목명, 보조 수치 등에 사용합니다.

### 2.3. 타입별 사용 규칙

#### **2.3.1. Type: Display**

- status: SHOULD
    
    content: 메인 히어로, 브랜드 캠페인, 프로모션 등 시각적 강조가 필요한 대형 텍스트에 사용합니다.
    
- status: AVOID
    
    content: 일반적인 본문이나 설명 텍스트를 표현하는 용도로 사용하지 않습니다.
    

#### **2.3.2. Type: Heading**

- status: SHOULD
    
    content: 페이지의 대표 타이틀이나 주요 콘텐츠 영역을 구분하는 섹션 제목에 사용합니다.
    
- status: AVOID
    
    content: 일반적인 본문이나 인터랙션 요소의 기능성 텍스트를 표현하는 용도로 사용하지 않습니다.
    

#### **2.3.3. Type: Title**

- status: SHOULD
    
    content: 상품 카드, 콘텐츠 리스트, 배너 등 개별 콘텐츠와 컴포넌트의 제목에 사용합니다.
    
- status: AVOID
    
    content: 일반 설명 문단이나 기능성 버튼 텍스트를 대체하는 용도로 사용하지 않습니다.
    

#### **2.3.4. Type: Body**

- status: SHOULD
    
    content: 본문, 상세 설명, 이용 방법, 유의사항 등 주요 정보를 전달하는 텍스트에 사용합니다.
    
- status: SHOULD
    
    content: 버튼, 탭, 입력 요소 등 인터랙션 컴포넌트의 기능과 선택 항목을 안내하는 텍스트에도 사용합니다.
    
- status: AVOID
    
    content: 페이지나 콘텐츠의 제목을 표현하기 위한 용도로 사용하지 않습니다.
    

#### **2.3.5. Type: Caption**

- status: SHOULD
    
    content: 주요 정보에 수반되는 부가 설명, 보조 수치, 면책 조항 등 보조적인 텍스트에 사용합니다.
    
- status: AVOID
    
    content: 주요 본문이나 인터랙션 컴포넌트의 핵심 텍스트를 대체하는 용도로 사용하지 않습니다.
    

### 2.5. 내부 운영 규칙

#### 2.5.1. 배너 타이틀

- status: SHOULD
content: 메인 대형 키비주얼 배너의 타이틀은 Display 타입을 적용하고, PC는 md를 MO는 sm 사용을 권장합니다.
- status: SHOULD
content: 중간 크기 배너의 타이틀은 Heading 타입을 적용하고, PC는 md를 MO는 sm 사용을 권장합니다.
- status: SHOULD
content: 작은 크기 배너의 타이틀은 Title 타입을 적용하고, PC는 md 또는 lg를 MO는 sm 또는 md 사용을 권장합니다.

#### 2.5.2. 서체 적용 기준

- status: MUST
content: 영문 제품명에는 샤프산스(Sharp Sans)를 적용합니다.
- status: MUST
content: 영문 제품명을 제외한 한글, 영문 및 숫자에는 원폰트(OneKorean)를 적용합니다.
- status: AVOID
content: 닷컴 내 캠페인 배너에는 지정된 브랜드 기본 서체 외 다른 서체를 사용하지 않습니다.
- status: ALLOW
content: 가격 정보의 폰트 크기가 커서 시각적 강조가 필요한 경우, 샤프산스(Sharp Sans)를 선택적으로 적용할 수 있습니다.
