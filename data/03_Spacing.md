# 1. 개요

### 1.1. 정의

- UI 요소 간의 거리와 컴포넌트 내부의 여백을 제어합니다.
- 정보의 구조와 시각적 위계를 완성하는 무형의 그리드 시스템입니다.
- 표준 스케일인 4px 단위를 준수합니다.

### 1.2. 적용 상황

- 연관된 정보들을 그룹핑하여 가독성을 높여야 할 때 적용합니다.
- 화면 내 레이아웃(섹션, 컴포넌트 등) 간의 경계를 시각적으로 명확하게 구분 지을 때 적용합니다.

## 2. 사용 규칙 (Usage Rules)

##`[MUST]` :강제 `[SHOULD]` :권장 `[ALLOW]` :예외허용 `[AVOID]` :금지

### 2.1. 공통 규칙

- `[MUST]` 모든 여백 값은 디자인 토큰에 정의된 8의 배수를 사용합니다.
- `[MUST]` 임의의 홀수 값은 절대 사용할 수 없습니다.
- `[SHOULD]`  개별 수치 입력 대신 피그마의 스페이싱 토근 값으로 지정합니다.
- `[ALLOW]` 좁은 화면 내 복잡한 영역에 한해, 한단계 작은 토큰으로 일괄 축소 적용을 허용합니다.
- `[AVOID]` 동일한 위계의 간격을 불규칙 하게 적용하지 않습니다.
- `[AVOID]` 원하는 여백을 만들기 위해 서로 다른 두 개 이상의 토큰 값을 임의로 더하거나 중첩(Stacking)하여 사용하는 행위를 금지합니다.

### 2.2. Type 선택 규칙

- `엘리먼트 패딩` = `element inset` : 엘리먼트 외곽선 ↔ 내부 콘텐츠 좌우상하 여백 (버튼/인풋 등)
- `컴포넌트 패딩` = `component inset` : 컴포넌트 최외곽선 ↔ 내부 모든 콘텐츠 사방 여백 (상품 카드 패딩)
- `텍스트 + 아이콘` = `gap` : 레이블 텍스트 ↔ 가이드/알림/툴팁 아이콘
- `텍스트 + 텍스트` = `gap` : 메인 타이틀 ↔ 서브 설명 문구
- `데이터 + 단위` = `gap` : 상품 가격 숫자 ↔ 통화 단위(₩) 또는 할인율(%)
- `텍스트 + 뱃지` = `gap` : 품절/특가/해시태그 뱃지 ↔ 상품명 텍스트
- `엘리먼트 + 레이블` = `gap` : 체크박스/라디오 버튼 ↔ 선택지 레이블 텍스트
- `동급 엘리먼트 나열 가로` = `gap` : 주버튼(Primary) ↔ 부버튼(Secondary) (장바구니 ↔ 바로구매)
- `동급 엘리먼트 나열 세로` = `gap` : 텍스트 인풋 필드 ↔ 하단 에러/도움말 메시지 텍스트
- `반복 엘리먼트 나열 가로` = `gap` : 필터 칩 ↔ 필터 칩 (검색 결과 상단 해시태그형 칩 그룹)
- `썸네일 + 텍스트` = `grid` : 상품 썸네일 이미지 ↔ 상품 정보(가격/타이틀) 텍스트 세트
- `텍스트 그룹 + 엘리먼트` = `grid` : 상품 정보 텍스트 ↔ 액션 버튼 (카드 내 장바구니 담기 아이콘)
- `리스트 + 리스트` = `grid` : 탭(Tab) 바의 각 서브 메뉴 ↔ 인접한 서브 메뉴
- `컴포넌트 세로 확장` = `grid` : 아코디언(FAQ) 메뉴 타이틀 ↔ 펼쳐지는 하단 답변 영역
- `콘텐츠 블록 + 콘텐츠 블록` = `section` : 상품 기본 정보 섹션 ↔ 배송/반품 안내 또는 리뷰 섹션 (상하)
- `구분선 + 콘텐츠` = `section` : 섹션 디바이더(두꺼운 회색 선 등) ↔ 상하 콘텐츠 영역
- `타이틀 + 그리드 리스트` = `section` : 섹션 대제목(Heading) ↔ 하단 상품 카드 리스트 그리드 전체
- `배너 + 리스트` = `section` : 중간 광고/기획전 광고 배너 ↔ 아래 일반 상품 목록 섹션
- `추천 영역 + 메인 영역` = `section` : 함께 보면 좋은 상품(추천 섹션) ↔ 메인 구매 여정 섹션
- `디바이스 여백 + 콘텐츠` = `section` : 모바일/PC 스크린 최외곽 좌우 끝 ↔ 레이아웃 정렬선 (최소 안전 마진)
- `고정 영역 + 첫 콘텐츠` = `section` : 최상단 고정 네비게이션 바(GNB) 하단 ↔ 첫 번째 비주얼/콘텐츠 시작점
- `영역 + 영역 가로` = `section` : 좌측 필터 영역(LNB/사이드바) ↔ 우측 메인 상품 리스트 영역
- `콘텐츠 끝 + 푸터` = `section` : 최하단 마지막 섹션 ↔ 사이트 하단 정보 영역(Footer) 시작점
- `플로팅 요소 + 바닥 모서리` = `section` : 플로팅 액션 버튼(FAB / 위로가기 버튼) ↔ 화면 하단/우측 모서리 여백

### 2.2. Type=Inset 규칙

- `[MUST]` 버튼, 카드, 모달, 입력 필드 등 컨테이너 및 컴포넌트의 내부 패딩(`padding`) 설정에만 사용한다.
- `[SHOULD]` 컴포넌트 크기가 커질수록 `Inset` 스케일도 비례하여 확장 적용한다.
- `[ALLOW]` 텍스트 행간(Line-Height) 차이로 인해 보정이 필요한 특수 컴포넌트(예: 버튼 레이블)에 한해 상/하 패딩 값을 수치 토큰 내에서 다르게 분할 적용하는 것을 허용한다.
- `[AVOID]`컴포넌트 외부의 요소 간 간격을 넓히기 위해 Inset 토큰을 `Margin` 용도로 사용하는 것을 금지한다.

### 2.3. Type=Gap 규칙

- `[MUST]` `글자 + 시각 요소` 구조를 설계할 때, `4px` 간격을 고정하여 적용한다.
- `[MUST]` `인라인` , `스택` 구조 요소 간의 간격에만 사용한다.
- `[MUST]` `글자 + 타이포` 구조로 메인 타이틀과 서브 문구를 배치할 때, `4px` 간격을 적용한다.
- `[MUST]` `데이터 + 단위` 구조로 상품 가격과 통화/할인율을 결합할 때, 정의된 간격 스펙을 준수한다.

### 2.4. Type=Grid 규칙

- `[MUST]` 인라인 요소보다 크고 페이지 섹션보다 작은 **중간 규모의 블록 단위 간격**(예: 타이틀 그룹–컨텐츠 그룹 사이, 모듈 간 간격)에 사용한다.
- `[SHOULD]` 카드 내 서브 구조 분리, 폼(Form) 그룹 간 간격, 타이틀–본문 블록 간격 등 컴포넌트 내/외부의 **중간 레이어 스페이싱**으로 적극 활용한다.
- `[ALLOW]` 화면의 기본 레이아웃 컬럼 간격(Gutter)이나 좌우 마진(Margin) 수치로 할당하여 사용하는 것을 허용한다.
- `[AVOID]` 컴포넌트 내부의 소형 요소 배치나 리스트 항목 간의 여백에 Grid 토큰을 혼용하는 것을 금지한다.

### 2.5. Type=Section 규칙

- `[MUST]` 독립된 주요 콘텐츠 블록, 페이지 섹션, 또는 대형 컴포넌트 단위 간의 상하 거리 구획에만 사용한다.
- `[SHOULD]` 카드 내 서브 구조 분리, 폼(Form) 그룹 간 간격, 타이틀–본문 블록 간격 등 컴포넌트 내/외부의 **중간 레이어 스페이싱**으로 적극 활용한다.
- `[ALLOW]` 랜딩 페이지나 비주얼 프로모션 영역처럼 극적인 공간 분리가 필요한 경우 토큰을 초과하는 스케일의 적용을 허용한다.
- `[AVOID]` 카드 내부의 타이틀과 본문 간격 등 좁은 영역의 구조 분리에 Section 토큰을 사용하는 것을 금지한다.
