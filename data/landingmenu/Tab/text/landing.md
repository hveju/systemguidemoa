# 타이틀
Tab의 구성이에요.
어떤게 궁금하신가요?

## 핵심만 보기

### Standard / Anchor
텍스트로 콘텐츠를 구분하고 전환할 때 사용

![](img_Tab_all_01)

### Icon
아이콘과 텍스트를 함께 제공하는 카드형 탭에 사용

![](img_Tab_all_02)

### Outlined
둥근 테두리로 선택 상태를 구분할 때 사용

![](img_Tab_all_03)

### Filled
배경색을 채워 선택된 항목을 강조할 때 사용

![](img_Tab_all_04)

### Toggle
컨테이너와 테두리로 선택 상태를 강조할 때 사용

![](img_Tab_all_05)

### Underlined / Standard / Primary
PC에서 밑줄로 선택 상태를 구분할 때 사용

![](img_Tab_all_06)

## Standard / Anchor

### Standard / Anchor는 텍스트 레이블과 Underline으로 콘텐츠를 구분하고 전환하는 탭이에요.
텍스트 중심으로 카테고리를 구분하고, 선택항목을 하단 밑줄로 표시합니다.

![](img_Tab_all_01)

추가 질문: 스펙 및 토큰, Badge, Chip

## Icon

### Icon은 아이콘과 텍스트로 구성된 카드형 탭이에요.
아이콘을 통해 항목의 의미를 시각적으로 전달하고 콘텐츠를 전환할 수 있습니다.

![](img_Tab_all_02)

추가 질문: 스펙 및 토큰, Badge, Chip

## Outlined

### Outlined은 둥근 외곽 테두리로 선택 상태를 표현하는 탭이에요.
테두리의 색상과 두께로 선택 항목을 구분합니다.

![](img_Tab_all_03)

추가 질문: 스펙 및 토큰, Badge, Chip

## Filled

### Filled는 선택된 항목의 배경색을 채워 강조하는 탭이에요.
선택된 항목에 검정색 배경과 흰색 텍스트를 적용해 활성 상태를 명확하게 표현합니다.

![](img_Tab_all_04)

추가 질문: 스펙 및 토큰, Badge, Chip

## Toggle

### Toggle은 선택된 항목의 컨테이너와 테두리를 강조하는 탭이에요.
선택 시 흰색 컨테이너와 검정색 테두리로 구분합니다.

![](img_Tab_all_05)

추가 질문: 스펙 및 토큰, Badge, Chip

## Underlined / Standard / Primary

### Underlined / Standard / Primary는 PC에서 사용하는 하단 밑줄 탭이에요.
텍스트 레이블 하단에 하단 밑줄을 표시해 선택된 항목을 구분합니다.

![](img_Tab_all_06)

추가 질문: 스펙 및 토큰, Badge, Chip
